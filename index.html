02 / About
Developer focused on systems software and cybersecurity

Exploring systems. Building tools. Learning by doing.

I'm Morrow — a developer from Donetsk region, Ukraine. My path into code started with a small IT school, and grew from there into years of independent study, late-night experiments, and building real projects instead of just reading about them.

Today I work mostly in Rust, building tools that need to be fast, safe and predictable — from PC monitoring utilities to early computer vision experiments. Rust shapes how I approach software: memory safety first, performance second, and no shortcuts in between.

Outside of code I write about my work in public — on Telegram, TikTok and GitHub — and I'm working toward launching a YouTube channel. I build in the open, learn as I go, and stay open to collaborations.
